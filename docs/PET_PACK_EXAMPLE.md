# Creating your first Potassium pet

1. Create a folder containing `manifest.json`, `model.json`, and optionally `animation.json` and `texture.png`.
2. Follow `PET_PACK_FORMAT.md`.
3. ZIP the files without an extra parent folder.
4. Rename the ZIP to `MyPet.potpet`.
5. Start Minecraft with Potassium.
6. Open the Pet Menu.
7. Paste the full path to `MyPet.potpet` and press Import.
8. Use the Pet button to cycle to the imported pet.

No server installation is required because Potassium pets are client-side cosmetics.
